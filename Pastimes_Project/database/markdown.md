# Pastimes Online Store

A PHP & MySQL marketplace for second‑hand clothing.  
Built as a university web development project.

## Features
- User registration & login (bcrypt)
- Seller verification (admin)
- Product upload & browsing
- Shopping cart (session)
- Direct messaging
- Responsive design

## Setup
1. Import `database/pastimes.sql` into MySQL.
2. Edit `includes/config.php` with your DB credentials.
3. Run with XAMPP/WAMP (PHP 7.4+).
4. Default admin: `admin` / `admin123`.
